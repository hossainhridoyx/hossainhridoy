## ✨ Features

- 🎨 **Modern UI** — Clean green-and-white theme with glassmorphism effects
- 🌀 **Animated hero section** — Rotating ring, floating profile image, gradient text
- 📋 **About Me section** — Compact two-column info panel with shimmer accent
- 🚀 **Projects section** — Cards for HridoyTV & AiPhotoz with hover animations
- 🔗 **Social links** — Facebook, TikTok, Telegram, IMO
- 📱 **Fully responsive** — Mobile, tablet & desktop friendly
- ⚡ **Scroll reveal animations** — Elements animate in as you scroll
- 🪶 **Zero dependencies** — Pure HTML, CSS & Vanilla JS (no frameworks)

## 🚀 Getting Started

### Run Locally

```bash
# Clone the repository
git clone https://github.com/YOUR_USERNAME/YOUR_REPO_NAME.git

# Open in browser
cd YOUR_REPO_NAME
open index.html
```

No build step needed — just open `index.html` in any browser.

### Deploy Free

You can deploy this on:
- **Vercel** — drag & drop the file at [vercel.com](https://vercel.com)
- **Netlify** — drag & drop at [netlify.com](https://netlify.com)
- **GitHub Pages** — enable in repo Settings → Pages
